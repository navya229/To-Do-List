document.addEventListener("DOMContentLoaded", () => {


What it does:
This line waits until the whole HTML page (the Document Object Model, or DOM) is fully loaded before running your JavaScript code.

Concept:

document represents the whole webpage.

addEventListener listens for an event (here "DOMContentLoaded") and then runs the function after the HTML elements are ready.

Why it’s needed:
It prevents errors that happen when you try to access HTML elements before they’re created.

🧩 Summary of Main Concepts
Concept	Meaning
DOM	-The tree structure representing your webpage’s HTML elements.
Event Listener-	Runs a function when an event (click, keypress, etc.) happens.
Functions-	Blocks of code that can be called multiple times.
Arrays & Objects-	Ways to store multiple pieces of data together.
Local Storage-  Built-in browser memory that stores data permanently.
JSON-	Format to convert data to/from text for storage.
Template Literals-	Use backticks to embed variables inside strings easily.
ClassList & Toggle-	Change CSS styles dynamically.
